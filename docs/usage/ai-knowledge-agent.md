# AI 知识管理使用说明

## 启用与授权

知识库管理员在“知识收件箱 → 管理设置”中选择：关闭、手动保存或自动草稿。选择已配置的模型或复用聊天模型，勾选数据传输许可，选择用户、目录及每日调用预算，保存设置。默认关闭不会改变原前台问答。

用户必须已有后台文档管理权限，AI 无法赋予或扩大权限。前台访客、机器人和只读用户不进入管理写入链路。

## 整理对话

在“知识助手”中正常交流，可说“把刚才讨论的内容整理到知识库”，也可以点击“整理当前对话”。任务先返回已提交，完成后在收件箱查看；此时内容尚未正式发布。

自动草稿模式累计三轮完整对话或闲置五分钟后异步整理。闲聊和没有新增价值的重复内容会被忽略。API Key、密码及隐私不应输入或保存；系统规则不能代替人工确认共享范围。

## 审核与发布

打开建议，核对标题、来源依据、风险、分类和正文 Diff。使用现有编辑器调整建议。修改标题、目标文档或目录后先保存，再核对正文。切换目标文档会重新读取其基线，避免将旧文档正文覆盖到新目标。

批准并发布后才写入正式文档。中高风险需要明确确认，冲突或合并建议必须人工编辑成可发布结果。若文档已被别人修改，系统返回版本冲突，应重新提取或基于最新文档编辑，不能强制覆盖。

可批量批准低风险建议；每条结果独立，以实际发布结果为准。拒绝的内容不进入 RAG。只有来源会话所有者能查看原聊天；其他审核者看到候选和理由，不会取得私有聊天访问权限。

## 任务、历史与恢复

在处理任务页查看失败、预算暂停和重试状态。重新提取会把旧候选标为拒绝并重新处理冻结来源。已发布更新可以创建高风险回滚建议，审核后走同一发布流程；新建文档不会由 AI 自动删除。

索引投递完成不等于学习成功，请在原文档页检查学习状态并验证检索。会话被删除时来源显示失效，已发布正文和审计记录仍受知识库权限保护。
